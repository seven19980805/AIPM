## 2. 背景与目标

### 2.1 背景

[描述 ABF 产品良率管理现状、当前痛点、使用人群、决策场景，以及为什么需要该分析页面。]

示例：ABF 制程跨多个站点和检测环节，业务需要快速识别良率下降来自产品、批次、Panel、站点、设备还是缺陷类别，并将分析结果用于日常质量会议、异常响应和改善追踪。

### 2.2 分析目标

- 按时间、产品、料号、批次、Panel、站点、设备和缺陷类别展示 ABF 良率表现。
- 识别良率损失最大的站点、缺陷类型和批次，支持 Pareto 排序。
- 支持从总体良率下钻到批次 / Panel / 站点 / 缺陷明细。
- 标准化良率口径、数据来源、筛选逻辑和验收标准，减少人工对账。
- 为异常告警、责任分派和改善闭环提供数据基础。

### 2.3 成功标准

- 业务负责人确认良率公式、剔除项、返工/重测处理和目标阈值。
- 看板数据与已批准来源查询或现有质量报表结果一致。
- 用户能在约定时间内定位主要良率损失来源和相关明细。
- 筛选、下钻、导出和权限规则在代表性场景中表现一致。

## 5. 良率口径与业务规则

### 5.1 良率公式

| 指标 | 公式 / 口径 | 粒度 | 备注 |
| --- | --- | --- | --- |
| 总良率 | [良品数量 / 投入数量] | 产品 / 批次 / 周期 | 明确是否包含返工后通过数量。 |
| 站点良率 | [站点通过数量 / 站点投入数量] | 站点 / 设备 / 批次 | 明确站点入口和出口定义。 |
| 一次通过率 | [未返工直接通过数量 / 投入数量] | 产品 / 站点 | 用于识别隐藏返工成本。 |
| 报废率 | [报废数量 / 投入数量] | 缺陷 / 站点 | 与返工、Hold、待判定分开统计。 |
| 良率损失贡献 | [某缺陷或站点损失数量 / 总损失数量] | 缺陷 / 站点 | 用于 Pareto 分析。 |

### 5.2 口径规则

- 定义分子、分母、投入数量、良品数量、不良数量、报废数量和返工数量。
- 明确工程批、试产批、Hold 批、重测记录、返工记录和取消批次是否纳入。
- 明确时间归属使用投料时间、站点完成时间、测试完成时间还是入库时间。
- 同一指标在 KPI、趋势图、明细表和导出中必须使用同一计算逻辑。
- 所有百分比、数量单位、舍入规则和空值处理需在文档中固定。

## 10. 下钻与根因分析

| 路径 | 说明 | 输出 |
| --- | --- | --- |
| 产品 -> 批次 | 查看某产品下低良率批次。 | 批次列表、批次良率、目标差异。 |
| 批次 -> Panel | 查看批次内 Panel 分布。 | Panel 良率、缺陷数量、状态。 |
| Panel -> 站点 | 追踪 Panel 在各站点表现。 | 站点通过/失败、时间、设备。 |
| 站点 -> 缺陷 | 查看站点主要缺陷。 | 缺陷 Pareto、缺陷明细。 |
| 缺陷 -> 设备 / 参数 | 分析缺陷是否集中在设备或参数区间。 | 设备对比、参数备注、改善记录。 |

根因辅助规则：

- 支持按损失贡献从高到低排序，默认展示 Top 10。
- 同一站点需支持按设备、班次、产品、批次对比。
- 异常点需展示计算口径、筛选条件和最后刷新时间。
- 用户可记录原因分类、责任部门、临时措施和长期措施。

## 13. 技术规格与非功能需求

| 类别 | 要求 |
| --- | --- |
| API / 聚合 | 明确请求参数、响应结构、分页、排序、聚合层级和错误码。 |
